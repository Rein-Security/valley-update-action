# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: on this repository, open **Security → Report a vulnerability**. Please don't open a public issue, pull request, or discussion for a security problem.

Include what you found, how to reproduce it, and the action version (tag or commit SHA) you tested. Never include your registry password, your valley ID, or your configuration in a report.

We acknowledge reports within 3 business days and keep you updated until the issue is resolved.

## Supported versions

Only the latest release of the current major version (`v1`) receives security fixes. Pin `@v1` to get them automatically, or pin a commit SHA and update it when a fix is released.
